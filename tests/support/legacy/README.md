# Arsip GUI 0.3.1

Arsip memuat app/ui/__init__.py, __main__.py, desktop.py persis dari checkpoint 0.3.1. Hash tiap source ada di gui-sha256.json. Ini bukan antarmuka aplikasi 0.3.2 dan tidak diekstrak/dijalankan otomatis.

Untuk pemulihan, gunakan paket checkpoint 0.3.1 yang tetap tersedia, atau ekstrak arsip ke salinan terpisah source 0.3.1. Jangan menimpa instalasi/workspace aktif. Tkinter/display diperlukan hanya untuk GUI lama.
