# Contributing

Keep reverse-engineering evidence separate from assumptions.

For research:
1. Record the source/evidence.
2. Record the address/file/offset where applicable.
3. Give discoveries a confidence level: UNKNOWN, LOW, MEDIUM, HIGH, CONFIRMED.
4. Do not commit commercial game data or copyrighted extracted assets.

For code:
- Keep format parsers deterministic.
- Add tests for newly discovered structures.
- Document unknown fields instead of guessing.
